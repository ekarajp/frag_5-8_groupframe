ขอบเขตผล

ตรวจ 500 IDs ตามลำดับ catalog, hash ทุกโมเดลและหลักฐาน 845 ไฟล์, replay คำสั่งก่อสร้างครบ 1,000 ทิศทาง และทดสอบย้าย loader กับตัวอย่างแรก/ท้ายรวม 4 ทิศทาง โดยไม่ import OpenSees หรือเรียก analysis

คำสั่งก่อสร้างครอบคลุม material, section, topology, masses และ gravity loads แต่ยังไม่ทำ gravity analysis หรือกำหนด damping โดย loader; โปรแกรมวิเคราะห์แยกต้องใช้ effective_development_protocol.json การตั้งค่า IDA แบบทั่วไปใน recipe เป็นข้อมูลที่เก็บไว้และไม่ใช่คำสั่งให้เปิด population analysis

Signed SPO ใช้ initial excursion/common domain; mesh16 มี valid prefix 46/48 และ alternative 47/48 กรณี จุดปลายผิดปกติและ cyclic attempts/failures/coverage ถูกเก็บไว้ ผลนี้ไม่ใช่การรับรอง static/cyclic ผ่านทุกกรณี ไม่ใช่ MIDR accuracy 80%, General-GM validation หรือหลักฐานการพังทางกายภาพ
